# CellGame26 playtest build

A test build of a cell-biology game in progress. The text is placeholder, and some animations aren't built yet.

**Build:** Level 1, preview of `059c4421` (2026-10-07).

## Level 1 playtest (for testers)

About 10 to 15 minutes. Use a Chromebook if you can, or your own laptop, with the browser window as large as it goes.

**[Play Level 1](https://naddicott-dtech.github.io/CellGame26-Playtest/)**: choose **Start level-1**. Ignore **Start slice**, which is a developer test scene.

1. **Play it normally** until "Level complete!". Read the dialogue boxes and click **Next** or **Continue**, or press **Enter**.
2. **Note anything that confused you**, especially:
   - **The first pseudopod:** how long did it take you to make the cell move for the first time? How many tries didn't work first?
   - **Finding glucose:** did it feel like exploring and finding food, or did it feel like food was put in front of you? Did you notice any pattern in where the glucose was?
   - **Refusals:** if a pull was refused (a red flash and a message), did you understand why, and what to do instead?
   - **The dialogue box:** was it clear when to read and when to play?
   - **Anything else:** a moment you didn't know what to do, or a message you didn't understand.
3. **Known gaps (no need to report):**
   - The lines in the dialogue boxes are placeholders.
   - When a dialogue box waits a few seconds before **Continue** is ready, that's where an animation will go: it isn't built yet.

**Send back** your notes, labelled with the device (the Chromebook model, or "own laptop") and how long the level took you (it's on the results screen).
